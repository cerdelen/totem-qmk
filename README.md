# Totem — QMK / Vial

QMK firmware for the **Totem** split keyboard (Seeed XIAO RP2040) with **Vial**.

## Download

Grab the zip from [Releases](../../releases).

| File | What it is |
|---|---|
| `totem_vial.uf2` | Vial firmware, for **both** halves |
| `totem_default.uf2` | Stock firmware without Vial, as a fallback |

## Install

Double-tap reset on one half, drag `totem_vial.uf2` onto the `RPI-RP2` drive, repeat on the other half. Plug the USB cable into the left half.

## Remap

Open [vial.rocks](https://vial.rocks) in Chrome or Edge.
