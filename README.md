# Totem - QMK Firmware

Firmware QMK para el teclado split **Totem**.

## 📋 Especificaciones

| Característica | Especificación |
|----------------|----------------|
| Modelo | Totem |
| Firmware | QMK |
| Layout | Split column-staggered 3×5 + 3 thumb keys (38 teclas) |
| Switches compatibles | Kailh Choc (Low Profile) |
| PCB | Totem |
| Conexión | USB-C (Seeed XIAO RP2040 / XIAO BLE) |
